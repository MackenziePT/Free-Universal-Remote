Perguntas frequentes

Já posso descarregar o Universal Remote?

A versão pública ainda não está disponível. O projeto encontra-se em testes e preparação da distribuição oficial.

Preciso de instalar Python ou PowerShell manualmente?

Não. A pré-visualização Windows x64 já inclui Python e bibliotecas no próprio programa. O PowerShell é opcional: quando autorizado, a aplicação consulta a versão estável mais recente publicada pela Microsoft, verifica a assinatura e o SHA-256 e só a descarrega se for necessária. Não altera o PowerShell global do Windows.

É exclusivo do ChatGPT?

Não. O agente usa MCP local para clientes compatíveis. A ligação remota ao ChatGPT ou a outros serviços pela Internet exige emparelhamento e transporte autenticado, ainda não incluídos na pré-visualização pública.

Funciona em qualquer computador?

O instalador experimental atual foi testado num Windows 11 x64, mas a compatibilidade pública com Windows 10, diferentes computadores e ARM64 ainda exige testes independentes. Não anunciamos compatibilidade universal sem a validar.
