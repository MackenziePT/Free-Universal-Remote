# Contribuir para o Universal Remote

Estado: desenvolvimento privado; a licença e a política formal de contribuições ainda não foram aprovadas para publicação.

Princípios:
- Separar UI, motor nativo, gateway MCP e transportes remotos.
- Nenhuma integração concede permissões por si própria: autorização local e revogação obrigatórias.
- Nenhum plugin de controlo remoto de terceiros é dependência do produto.
- Respeitar a imutabilidade dos registos de operação e usar testes para alterações de comportamento.
- Não adicionar chaves, logs pessoais, binários de fornecedores nem caminhos do computador do autor ao controlo de versões.
- Executar os testes Windows e o MCP stdio no ambiente de desenvolvimento antes de propor alterações.

Antes de abrir o repositório, serão definidos a licença, o código de conduta e o processo de revisão.
